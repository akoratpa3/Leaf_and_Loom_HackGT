# Leaf & Loom: A marketplace for eco-friendly products (HackGT Final Project)

**Team:** Aditi Koratpallikar, Pooja Saji, Tanisha Paryani

## Tech Stack
-Python
-Django
-SQLite
-HTML/CSS

## Features
- **Buyer and seller accounts:** registration, login, buyer profiles, and seller profiles with a short bio and location
- **Product listings:** sellers add products with images, prices, and sustainability attributes (eco-friendly, locally made, recyclable, sustainable packaging, carbon footprint)
- **Marketplace:** browse all products, view product details, and check out
